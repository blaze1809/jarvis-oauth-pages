# Jarvis Personal AI

Jarvis is a privately hosted personal AI assistant that helps its owner manage projects, research, and automated workflows.

## Google Drive Integration

Jarvis uses the Google Drive API to publish and synchronize project context, documents, status reports, and backups with the owner's Google Drive.

Access is authorized by the owner through Google OAuth. The integration is intended for personal use and is not offered as a public service.

The Jarvis application itself is privately hosted and is not publicly accessible.
